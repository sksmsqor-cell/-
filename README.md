# 🤖 AI 네이버 블로그 글 생성기

> **바이브 코딩으로 만든 완성본**  
> 이런 걸 우리가 만들 수 있어요!  
> 먼저 실행해보고 "와, 이런 것도 되네?" 느껴보세요!

---

## 🎯 뭘 할 수 있나요?

**AI가 네이버 블로그 글을 자동으로 써줍니다!**

1. 내 글 스타일 AI가 분석 📝
2. 키워드만 넣으면 글 자동 생성 ✨
3. 복사해서 네이버에 붙이면 끝! (서식도 그대로) 🎨

**한 번에 10개, 20개도 만들 수 있어요!**

---

## 🚀 어떻게 쓰나요?

### 1️⃣ 실행하기
폴더에서 명령 프롬프트 열고:
```
node blog-server.js
```

### 2️⃣ 브라우저 열기
주소창에 입력:
```
http://localhost:3000
```

**끝! 이제 써보세요!** 🎉

---

## 💡 사용법 (5단계)

### 1단계: 내 글 붙여넣기 📝
평소에 쓴 블로그 글 2~3개 복사해서 붙여넣기  
→ **[스타일 분석]** 클릭

### 2단계: 가게 정보 입력 🏪
- 가게 이름
- 업종 (카페, 식당 등)
- 지역
- 강조할 점

### 3단계: 키워드 입력 🔑
```
강남 맛집
데이트 카페
주말 브런치
핫플 추천
```
한 줄에 하나씩!

### 4단계: 생성! ✨
**[글 생성]** 버튼만 누르면  
AI가 알아서 글을 뚝딱뚝딱 만들어줘요!

### 5단계: 복사하기 📋
- **[제목 복사]** → 제목칸에 붙이기
- **[본문 복사]** → 본문에 붙이기 (굵게, 줄바꿈 다 됨!)
- **[태그 복사]** → 태그 붙이기

**1~2분 안에 한 편 완성!**

## 🔐 알아둘 것 2가지

### 1. `.env` 파일이 뭔가요?
**비밀번호 파일**이에요.

- AI 쓰려면 비밀번호(API 키)가 필요해요
- 이 파일에 들어있어요
- **절대 공유 금지!** (카드 비밀번호랑 같아요)
- 강사님이 이미 넣어뒀으니 건들지 마세요!

### 2. `.gitignore` 파일이 뭔가요?
**자동 보안 장치**예요.

Git으로 코드를 올릴 때,  
비밀번호 파일(`.env`)은 절대 올리면 안 되잖아요?

이 파일이 "`.env`는 빼고 올려!"라고 자동으로 막아줘요.

## 🤔 Git이 뭔가요?

**코드 전용 구글 드라이브**라고 생각하면 돼요!

- 💾 코드 백업
- 📝 변경 기록 자동 저장
- 👥 여러 명이 함께 작업
- ⏰ 실수해도 이전 버전으로 되돌리기

**GitHub** = Git 코드 보관하는 인터넷 저장소  
(네이버 클라우드처럼요!)
