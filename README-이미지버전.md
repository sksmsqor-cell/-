# 🎨 AI 네이버 블로그 글 생성기 (이미지 포함)

> **바이브 코딩으로 만든 완성본**  
> 글도 쓰고 이미지도 자동으로 만들어줘요!  
> AI가 블로그 글 + 사진까지 한 번에!

---

## 🎯 뭘 할 수 있나요?

**AI가 네이버 블로그 글 + 이미지를 자동으로 만들어줍니다!**

1. 내 글 스타일 AI가 분석 📝
2. 키워드 하나면 글 + 이미지 6장 자동 생성 🎨
3. 복사해서 네이버에 붙이면 끝! (이미지까지 다!) 🖼️

**한 번에 10개, 20개도 만들 수 있어요!**

---

## 🚀 어떻게 쓰나요?

### 0️⃣ API 키 설정 (처음 한 번만)
1. `.env.example` 파일을 복사해서 `.env`로 이름 변경
2. `.env` 파일을 열어서 API 키 입력
   ```
   OPENROUTER_API_KEY=실제-키-입력
   HIGGSFIELD_API_KEY=실제-키:실제-시크릿
   ```
3. 저장하고 닫기

💡 **강사님이 이미 설정해뒀으면 이 단계는 건너뛰세요!**

### 1️⃣ 실행하기
폴더에서 명령 프롬프트 열고:
```
node blog-server-with-image.js
```

### 2️⃣ 브라우저 열기
주소창에 입력:
```
http://localhost:3000
```

**끝! 이제 써보세요!** 🎉

---

## 💡 사용법 (5단계)

### 1단계: 내 글 붙여넣기 📝
평소에 쓴 블로그 글 2~3개 복사해서 붙여넣기  
→ **[스타일 분석]** 클릭

### 2단계: 가게 정보 입력 🏪
- 가게 이름
- 업종 (카페, 식당 등)
- 지역
- 강조할 점

### 3단계: 키워드 입력 🔑
```
강남 맛집
데이트 카페
주말 브런치
핫플 추천
```
한 줄에 하나씩!

### 4단계: 생성! ✨
**[글 생성]** 버튼만 누르면  
AI가 알아서 글 + 이미지 6장을 뚝딱뚝딱 만들어줘요!

⏱️ **소요 시간:** 글 하나당 20~30초 (이미지 생성 포함)

### 5단계: 복사하기 📋
- **[제목 복사]** → 제목칸에 붙이기
- **[본문 복사]** → 본문에 붙이기 (이미지도 다 들어가요!)
- **[태그 복사]** → 태그 붙이기

**2~3분 안에 한 편 완성!**

## 🎨 이미지 생성 정보

**사용 모델:** Higgsfield Ideogram v4.0

**특징:**
- 📸 글 내용에 맞는 이미지 자동 생성
- 🎯 소제목마다 적절한 사진 배치
- 🌏 한글/영어 모두 지원
- 🖼️ 고품질 4:3 비율 이미지

**생성 속도:**
- 이미지 1장당 5~10초
- 글 하나당 총 6장 생성
- 여러 개 동시 생성으로 빠르게!

## 🔐 알아둘 것 3가지

### 1. `.env` 파일이 뭔가요?
**비밀번호 파일**이에요.

- AI 쓰려면 비밀번호(API 키) 2개가 필요해요
  * OpenRouter: 글 생성용
  * Higgsfield: 이미지 생성용
- 이 파일에 들어있어요
- **절대 공유 금지!** (카드 비밀번호랑 같아요)
- 강사님이 이미 넣어뒀으니 건들지 마세요!

### 2. `.env.example` 파일이 뭔가요?
**API 키 설정 안내서**예요.

- 실제 API 키는 없고, 형식만 보여줘요
- 처음 설정할 때 이걸 복사해서 `.env` 만들면 돼요
- 이 파일은 GitHub에 올려도 안전해요 (키가 없으니까!)

### 3. `.gitignore` 파일이 뭔가요?
**자동 보안 장치**예요.

Git으로 코드를 올릴 때,  
비밀번호 파일(`.env`)은 절대 올리면 안 되잖아요?

이 파일이 "`.env`는 빼고 올려!"라고 자동으로 막아줘요.

**파일 정리:**
- `.env` → 실제 비밀번호 (Git에 올리면 안 됨!)
- `.env.example` → 설정 안내서 (Git에 올려도 됨!)
- `.gitignore` → .env 자동 차단 (Git에 올려야 함!)

## 🆚 텍스트 버전 vs 이미지 버전

### 텍스트 버전 (blog-server.js)
- ✅ 빠른 속도 (글만 생성)
- ✅ 간단한 사용
- ❌ 이미지 없음

### 이미지 버전 (blog-server-with-image.js) ⭐ 현재 버전
- ✅ 글 + 이미지 자동 생성
- ✅ 완전 자동화
- ⏱️ 조금 느림 (20~30초)

**처음엔 텍스트 버전으로 연습하고,
